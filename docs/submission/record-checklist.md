# RECORD checklist

Reporting of studies Conducted using Observational Routinely-collected health Data (RECORD), the STROBE
extension (Benchimol EI et al. PLoS Med 2015;12(10):e1001885). Item wording below is paraphrased from the
published checklist; the verbatim checklist is at record-statement.org.
Section references are to the manuscript.

| Item | STROBE / RECORD requirement (paraphrased) | Where addressed |
|---|---|---|
| 1 (a) | Design term in the title or abstract | Title ("pre-registered study"); Abstract, Methods |
| 1 (b) | Informative, balanced abstract | Abstract |
| RECORD 1.1 | Type of data used named in the title or abstract | Title and Abstract: v-safe free text; Abstract, Methods: VAERS, CDC MedDRA coding |
| RECORD 1.2 | Geographic region and time frame in the title or abstract | Abstract and Introduction: United States, v-safe (2020 to 2023 check-ins); Methods, Data sources (VAERS data dated 2026-06-03) |
| RECORD 1.3 | Database linkage stated in the title or abstract | Abstract (Methods): linkage to CDC MedDRA coding and to VAERS via the call centre and OpenVSafe |
| 2 | Background and rationale | Introduction |
| 3 | Objectives and pre-specified hypotheses | Introduction (four questions); Methods, Pre-registration |
| 4 | Study design | Methods (pre-registered observational analysis of routinely collected surveillance data) |
| 5 | Setting, locations, dates | Methods, Data sources |
| 6 (a) | Eligibility, sources, selection | Methods, Case definition and comparison groups |
| RECORD 6.1 | Population selection codes or algorithms | Methods, Case definition (three criteria); Classification (taxonomy v1.0, frozen); repository |
| RECORD 6.2 | Validation of selection codes or algorithms | Methods, Validation and the confirmatory gate; Results, Classifier validation; Table 2 (model sensitivity) |
| RECORD 6.3 | Linkage flow diagram | Results, Corpus (entry counts by survey match); a flow figure can be added at revision if requested |
| 7 | Variables defined | Methods, Classification; Case definition; Statistical analysis |
| RECORD 7.1 | Complete list of codes and algorithms | Repository: taxonomy/v1.0 (themes and MedDRA map), classifier prompt v0.1; Methods, Decisions where the registration was silent |

| 9 | Bias | Limitations (classifier gate, reference standard, unequal classification, attrition, exclusions, verbosity) |

| RECORD 12.1 | Access to the database population | Methods, Data sources: full FOIA releases, all records |
| RECORD 12.2 | Data cleaning | Methods, Data sources (de-duplication, redaction); Results, Corpus (row counts) |

| 14 | Descriptive data | Results, Table 1 |
